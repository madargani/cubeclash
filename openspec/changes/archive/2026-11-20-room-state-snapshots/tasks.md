Verify: interfaces match the design (artifact); the server build stays red until 2.3-2.6 land (expected).
- [x] 2.3 Rewrite `apps/server/src/rooms.ts` to the new data model: `createRoom(nickname)` issues `crypto.randomUUID()` member ids and sets `hostMemberId`; `addMember(roomId, nickname)` issues a member id and returns the new `Member` with `connected: true`; add `setMemberConnected(roomId, memberId, connected)`, `getMember(roomId, memberId)`, and `countConnected(roomId)`; delete `removeMember`; `areAllDone` counts **connected** members only (design D2); `canStartNextRound` and `incrementRound` use `room.settings.rounds - 1` instead of the hardcoded 4 (design D9); keep `startGame`, `addResult` (double-submit guard unchanged), `updateSettings` (existing validation guards unchanged), `getRoom`, `getCurrentRound`, `deleteRoom`, `roomExists`. - [x] 2.5 Rewrite `apps/server/src/handlers/roomHandlers.ts`: `create_room` issues ids, `socket.join`s, binds `socket.data = { roomId, memberId }`, acks `{ roomId, memberId }`, broadcasts; `join_room` rejects a socket already bound to a room, rejects unknown rooms and taken nicknames (checked against all members, connected or not), initializes the joiner's results row to `round + 1` nulls when `room.round >= 0` (design D5), binds, acks `{ memberId }`, broadcasts; new `rejoin_room` handler rejects unknown room/member, rejects an already-connected member with "Already connected", otherwise rebinds, `setMemberConnected(..., true)`, acks success, broadcasts; `update_settings` guards on the derived host plus the existing settings rules, then broadcasts; `disconnecting` resolves the room from `socket.data.roomId`, marks the member disconnected, deletes the room only when `countConnected === 0`, otherwise broadcasts (design D6 — host disconnect no longer deletes rooms or disconnects other sockets). Verify: every successful mutation path ends in `broadcastRoomState` (artifact).
- [x] 2.6 Rewrite `apps/server/src/handlers/gameHandlers.ts`: `start_game` guards (room exists, actor is the derived host, `scrambles.length === 0`), calls `startGame`, awaits `generateScramble` and pushes the scramble **before** broadcasting; `next_round` guards (derived host, `canStartNextRound`, `incrementRound` succeeds), pushes scramble, broadcasts; `submit_solve(time)` resolves room and member from `socket.data`, calls `addResult`, broadcasts — no `round_done`/`game_over` emits and no `room.round === 4` branch (phase derivation covers it, design D9). Verify: `npm run build -w server` passes — the server fully compiles on the new model.
